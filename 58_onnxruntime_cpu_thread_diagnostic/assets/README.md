# Day58 benchmark assets

Day58 does not duplicate image files. It reuses the six tracked, source-attributed inputs from
`../55_onnxruntime_cpp_benchmark/assets/` so that input composition is identical across every
thread condition and directly comparable with Day57.

These images are performance-regression inputs only. They are not accuracy, class-coverage,
external-generalization, or open-set evidence for the forest-species classifier.
