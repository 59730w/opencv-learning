# Day33：NiN（网络中的网络）\+ GoogLeNet（含并行连结的网络）

**核心主题**：1×1 卷积的两种高阶用法——NiN 用它替代全连接 → GoogLeNet 用它做瓶颈降维 → Inception 模块（四条并行路径 \+ 通道拼接）

---

## 第一部分：NiN——网络中的网络

### 1\.1 核心批判：全连接层是“罪魁祸首”

回顾 AlexNet 和 VGG 网络结构，**全连接层占据了模型绝大部分参数量**，是导致模型臃肿、过拟合的核心原因。

|网络|全连接层参数|卷积层参数|全连接层参数占比|
|---|---|---|---|
|AlexNet|≈ 43M|≈ 3\.7M|**92%**|
|VGG\-11|≈ 119M|≈ 9\.5M|**93%**|

**NiN 核心创新**：彻底舍弃传统全连接层！采用 **1×1 卷积 \+ 全局自适应平均池化** 替代完整分类头。

### 1\.2 NiN 块——在卷积层内部嵌入“微型 MLP”

```python
import torch.nn as nn

def nin_block(in_channels, out_channels, kernel_size, strides, padding):
    return nn.Sequential(
        # 空间卷积：提取图像空间特征
        nn.Conv2d(in_channels, out_channels, kernel_size, strides, padding),
        nn.ReLU(),
        # 两层1×1卷积：逐像素通道非线性变换（微型MLP）
        nn.Conv2d(out_channels, out_channels, kernel_size=1), nn.ReLU(),
        nn.Conv2d(out_channels, out_channels, kernel_size=1), nn.ReLU()
    )

```

**NiN 块组成规则**：1层可变核空间卷积 \+ 2层1×1卷积，在不改变特征图尺寸的前提下，对每个像素的通道向量做双层非线性变换。

|层级|卷积核大小|核心作用|
|---|---|---|
|第一层|11×11 / 5×5 / 3×3（可变）|提取图像空间结构、纹理、轮廓特征|
|第二层|1×1|实现通道间非线性组合，等价像素级共享MLP|
|第三层|1×1|进一步加深通道非线性变换，提升特征表达能力|

**核心原理**：NiN 将1×1卷积的作用发挥到极致，在常规卷积后堆叠两层1×1卷积，相当于在卷积网络内部嵌入微型全连接网络，这也是 **Network in Network（网络中的网络）** 的命名由来。

### 1\.3 NiN 完整网络结构

```python
net = nn.Sequential(
    # 第一级NiN块+池化
    nin_block(1,  96,  kernel_size=11, strides=4, padding=0),
    nn.MaxPool2d(3, stride=2),
    # 第二级NiN块+池化
    nin_block(96, 256, kernel_size=5,  strides=1, padding=2),
    nn.MaxPool2d(3, stride=2),
    # 第三级NiN块+池化
    nin_block(256, 384, kernel_size=3,  strides=1, padding=1),
    nn.MaxPool2d(3, stride=2),
    # 正则化防过拟合
    nn.Dropout(0.5),
    # 最终分类NiN块：输出10分类通道
    nin_block(384, 10, kernel_size=3,  strides=1, padding=1),
    # 全局自适应平均池化：彻底替代全连接层
    nn.AdaptiveAvgPool2d((1, 1)),
    # 展平得到分类结果
    nn.Flatten()
)

```

### 1\.4 逐层形状流转（输入224×224）

输入尺寸：(1, 1, 224, 224\)

nin\_block(1→96,11,s=4\) → (1, 96, 54, 54\)  尺寸计算：(224\-11\)/4\+1=54

MaxPool(3,s=2\) → (1, 96, 26, 26\)  尺寸计算：(54\-3\)/2\+1=26

nin\_block(96→256,5,p=2\) → (1, 256, 26, 26\)  padding=2，尺寸保持不变

MaxPool(3,s=2\) → (1, 256, 12, 12\)  尺寸计算：(26\-3\)/2\+1=12

nin\_block(256→384,3,p=1\) → (1, 384, 12, 12\)  padding=1，尺寸保持不变

MaxPool(3,s=2\) → (1, 384, 5, 5\)  尺寸计算：(12\-3\)/2\+1=5

Dropout(0\.5\) → (1, 384, 5, 5\)  不改变特征尺寸

nin\_block(384→10,3,p=1\) → (1, 10, 5, 5\)  输出10分类对应通道

AdaptiveAvgPool2d((1,1\)\) → (1, 10, 1, 1\)  全局池化压缩尺寸

Flatten → (1, 10\)  直接输出10类分类logits

### 1\.5 AdaptiveAvgPool2d——池化界的万能钥匙

```python
nn.AdaptiveAvgPool2d((1, 1))

```

这是NiN最精巧的核心设计，彻底颠覆传统CNN分类结构：

|属性|详细说明|
|---|---|
|输入特性|支持任意 H×W 尺寸的特征图|
|输出特性|固定输出 1×1 尺寸特征图|
|运算逻辑|对单个通道的所有空间像素求均值，将二维空间特征压缩为单个标量|
|核心作用|完全替代 Flatten \+ 多层全连接的传统分类器|

**结构对比**

传统CNN（LeNet/AlexNet/VGG）：卷积特征 → (256,5,5\) → Flatten(6400维\) → 多层全连接 → 10分类

NiN网络：最后一级NiN块 → (10,5,5\) → 自适应全局池化 → Flatten(10维\) → 直接分类

**核心优势**：自适应池化让网络不依赖固定输入尺寸，可适配任意大小的输入图像，泛用性极强。

### 1\.6 NiN vs 传统CNN 核心对比

|特性|LeNet / AlexNet / VGG|NiN|
|---|---|---|
|分类器结构|Flatten \+ 多层全连接|NiN块 \+ 全局自适应平均池化|
|全连接参数量|数十MB，参数量庞大|0，无全连接参数|
|输入图像尺寸|固定尺寸，兼容性差|灵活任意尺寸，兼容性强|
|通道维度操作|仅全连接层做通道变换|每一层卷积都做通道非线性变换|
|过拟合风险|极高，全连接层冗余参数多|极低，无全连接冗余参数|

## 第二部分：GoogLeNet

### 2\.1 历史地位

GoogLeNet 诞生于2014年，是当年 ImageNet 图像分类竞赛的冠军模型。它吸收了 NiN 网络嵌套、1×1卷积轻量化的核心思想，并创新性引入**并行多尺度特征提取**机制，在大幅降低参数量与计算量的同时，显著提升模型特征表达能力。

该网络的命名致敬经典卷积网络 LeNet（Le→LeNet，GoogLe→GoogLeNet），虽致敬经典，但结构设计完全突破传统CNN串行堆叠的固有范式。

其核心里程碑贡献：提出 **Inception 模块**，让网络通过多条并行支路，同时提取不同感受野的特征，**自动学习最优特征尺度**，彻底摆脱人工固定卷积核尺寸的局限。

### 2\.2 Inception 模块——并行多尺度特征提取核心结构

Inception 模块是 GoogLeNet 的核心组成单元，摒弃了传统 CNN 单一卷积核逐层串行堆叠的模式，设计四条**并行特征提取路径**，分别捕获细粒度纹理、局部形状、全局上下文、显著性池化特征，最终在通道维度完成特征融合。

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class Inception(nn.Module):
    def __init__(self, in_channels, c1, c2, c3, c4, **kwargs):
        super().__init__()
        # 线路1：单1×1卷积，提取细粒度像素特征
        self.p1_1 = nn.Conv2d(in_channels, c1, kernel_size=1)
        # 线路2：1×1瓶颈降维 + 3×3中等感受野卷积
        self.p2_1 = nn.Conv2d(in_channels, c2[0], kernel_size=1)
        self.p2_2 = nn.Conv2d(c2[0], c2[1], kernel_size=3, padding=1)
        # 线路3：1×1瓶颈降维 + 5×5大感受野卷积
        self.p3_1 = nn.Conv2d(in_channels, c3[0], kernel_size=1)
        self.p3_2 = nn.Conv2d(c3[0], c3[1], kernel_size=5, padding=2)
        # 线路4：3×3最大池化 + 1×1通道维度调整
        self.p4_1 = nn.MaxPool2d(kernel_size=3, stride=1, padding=1)
        self.p4_2 = nn.Conv2d(in_channels, c4, kernel_size=1)

    def forward(self, x):
        p1 = F.relu(self.p1_1(x))
        p2 = F.relu(self.p2_2(F.relu(self.p2_1(x))))
        p3 = F.relu(self.p3_2(F.relu(self.p3_1(x))))
        p4 = F.relu(self.p4_2(self.p4_1(x)))
        # 通道维度拼接，融合多尺度特征
        return torch.cat((p1, p2, p3, p4), dim=1)

```

### 2\.3 Inception 模块四条路径图解与作用

输入特征图维度：(in\_channels, H, W\)

├─ 线路1：纯 1×1 卷积 → 输出 c1 通道细粒度特征

├─ 线路2：1×1 瓶颈降维 → 3×3 卷积 → 输出 c2[1\] 通道中等尺度空间特征

├─ 线路3：1×1 瓶颈降维 → 5×5 卷积 → 输出 c3[1\] 通道大尺度上下文特征

└─ 线路4：3×3 最大池化 → 1×1 卷积调通道 → 输出 c4 通道显著性特征

最终融合：四条路径输出在**通道维度拼接**，输出总通道数 = c1 \+ c2[1\] \+ c3[1\] \+ c4，特征图空间尺寸保持不变。

|并行线路|核心作用|设计意义|
|---|---|---|
|1×1 卷积支路|提取像素级纹理、颜色、细节特征|保留浅层细粒度信息，补充细节特征|
|1×1→3×3 卷积支路|提取局部轮廓、形状、结构特征|3×3卷积性价比最高，适配绝大多数物体局部特征|
|1×1→5×5 卷积支路|提取远距离像素关联、全局上下文特征|扩大感受野，捕获大尺度物体结构与全局信息|
|池化\+1×1 卷积支路|筛选显著特征，抑制冗余噪声|融合池化不变性特征，丰富特征维度|

**核心设计思想**：多感受野并行提取特征，网络可自主根据数据集特点，自适应侧重不同尺度特征，无需人工调参指定卷积核尺寸，泛化能力大幅提升。

### 2\.4 为什么 3×3 和 5×5 前面要加 1×1？——瓶颈层（Bottleneck）

直接使用3×3、5×5大核卷积计算量极大，**1×1卷积作为瓶颈层**，先压缩通道数再做大核卷积，大幅降低计算成本，是GoogLeNet轻量化的核心关键。

**无瓶颈层计算逻辑**：256通道输入 → 3×3卷积 → 128通道输出

计算量：256 × 128 × 3 × 3 × H × W = 294912 × H×W

**有瓶颈层计算逻辑**：256通道 → 1×1卷积压缩至96通道 → 3×3卷积升维至128通道

计算量：(256×96×1×1 \+ 96×128×3×3\) × H×W = 135168 × H×W

**优化效果**：计算量降低54%，同时新增一层ReLU非线性激活，在降参提速的同时，提升模型非线性表达能力。

### 2\.5 GoogLeNet 完整结构（5 个阶段）

GoogLeNet 用 b1\~b5 五个大阶段来组织网络，结构逻辑与 VGG 相似（分阶段降采样、升通道），核心区别是将普通卷积堆叠替换为 Inception 模块堆叠，实现多尺度特征深度融合。

```python
# GoogLeNet五阶段整体架构逻辑
# b1：快速降采样，压缩图像尺寸
b1 = nn.Sequential(nn.Conv2d(1,64,7,2,3), nn.ReLU(), nn.MaxPool2d(3,2,1))
# b2：通道升维，初步特征提取
b2 = nn.Sequential(nn.Conv2d(64,64,1), nn.ReLU(), nn.Conv2d(64,192,3,1,1), nn.ReLU(), nn.MaxPool2d(3,2,1))
# b3：双层Inception融合，初步多尺度特征提取
b3 = nn.Sequential(Inception(192,64,(96,128),(16,32),32), Inception(256,128,(128,192),(32,96),64), nn.MaxPool2d(3,2,1))
# b4：五层Inception深度特征提取，核心特征学习阶段
b4 = nn.Sequential(Inception(480,192,(96,208),(16,48),64),
                    Inception(512,160,(112,224),(24,64),64),
                    Inception(512,128,(128,256),(24,64),64),
                    Inception(512,112,(144,288),(32,64),64),
                    Inception(528,256,(160,320),(32,128),128),
                    nn.MaxPool2d(3,2,1))
# b5：最终特征融合，输出高维全局特征
b5 = nn.Sequential(Inception(832,256,(160,320),(32,128),128),
                    Inception(832,384,(192,384),(48,128),128))
# 完整分类头：全局池化+展平+单层全连接
net = nn.Sequential(b1, b2, b3, b4, b5,
                    nn.AdaptiveAvgPool2d((1,1)),
                    nn.Flatten(),
                    nn.Linear(1024, 10))

```

### 2\.6 逐层形状流转（96×96 输入）

GoogLeNet 针对 Fashion\-MNIST 数据集采用 96×96 小尺寸输入，无需原版224×224超大图像，适配小数据集训练：

输入:                     (1,   1, 96, 96\)

b1: Conv(1→64,7,s=2,p=3\): (1,  64, 48, 48\)   ← (96\+6\-7\)/2\+1=48

MaxPool(3,s=2,p=1\):    (1,  64, 24, 24\)   ← (48\+2\-3\)/2\+1=24

b2: Conv(64→64,1\):        (1,  64, 24, 24\)

Conv(64→192,3,p=1\):    (1, 192, 24, 24\)   ← padding=1 保持尺寸

MaxPool(3,s=2,p=1\):    (1, 192, 12, 12\)   ← (24\+2\-3\)/2\+1=12

b3: Inception(192→256\):    (1, 256, 12, 12\)

Inception(256→480\):    (1, 480, 12, 12\)

MaxPool(3,s=2,p=1\):    (1, 480,  6,  6\)   ← (12\+2\-3\)/2\+1=6

b4: Inception×5(480→\.\.\.→832\):

逐块通道增长，最后输出: (1, 832,  6,  6\)

MaxPool(3,s=2,p=1\):    (1, 832,  3,  3\)   ← (6\+2\-3\)/2\+1=3

b5: Inception(832→832\):   (1, 832,  3,  3\)

Inception(832→1024\):   (1,1024,  3,  3\)

AdaptiveAvgPool(1,1\):  (1,1024,  1,  1\)

Flatten:               (1,1024\)

Linear(1024, 10\):          (1, 10\)  → 10 类 logits

### 2\.7 Inception 各块通道分配速查表

规律：越深的 Inception 块，输出通道越多、特征维度越丰富，且所有3×3/5×5卷积前均配置1×1瓶颈降维，严格控制计算量。

|Inception 块|输入通道|c1(1×1\)|c2(1×1→3×3\)|c3(1×1→5×5\)|c4(pool→1×1\)|输出通道|
|---|---|---|---|---|---|---|
|3a|192|64|\(96, 128\)|\(16, 32\)|32|256|
|3b|256|128|\(128, 192\)|\(32, 96\)|64|480|
|4a|480|192|\(96, 208\)|\(16, 48\)|64|512|
|4b|512|160|\(112, 224\)|\(24, 64\)|64|512|
|4c|512|128|\(128, 256\)|\(24, 64\)|64|512|
|4d|512|112|\(144, 288\)|\(32, 64\)|64|528|
|4e|528|256|\(160, 320\)|\(32, 128\)|128|832|
|5a|832|256|\(160, 320\)|\(32, 128\)|128|832|
|5b|832|384|\(192, 384\)|\(48, 128\)|128|1024|

### 2\.8 Inception forward 中的 1×1 瓶颈 —— 注释图解

```python
def forward(self, x):
    # 线路1: 192 → 64（无瓶颈，直接1×1提取细粒度特征）
    p1 = F.relu(self.p1_1(x))                          # (batch, 64, H, W)
    # 线路2: 192 → 96 → 128（先瓶颈降维，再3×3扩维提取局部特征）
    p2 = F.relu(self.p2_2(F.relu(self.p2_1(x))))       # (batch, 128, H, W)
    # 线路3: 192 → 16 → 32（极致瓶颈压缩，适配5×5大核降计算量）
    p3 = F.relu(self.p3_2(F.relu(self.p3_1(x))))       # (batch, 32, H, W)
    # 线路4: 池化保尺寸 + 1×1调通道
    p4 = F.relu(self.p4_2(self.p4_1(x)))               # (batch, 32, H, W)
    # 通道维度拼接融合：64+128+32+32=256通道
    return torch.cat((p1, p2, p3, p4), dim=1)          # (batch, 256, H, W)

```

四条不同尺度、不同类型的特征在通道维度融合，让后续网络层可以自适应筛选有效特征、抑制冗余信息，极大提升模型的特征鲁棒性与泛化能力。

## 第三部分：NiN vs GoogLeNet——两种"去全连接"策略

|维度|NiN|GoogLeNet|
|---|---|---|
|核心模块|NiN Block（Conv \+ 1×1 \+ 1×1）|Inception（四条并行路径 \+ cat）|
|1×1 卷积用途|在每个像素位置增加非线性|瓶颈降维（控制整体计算量）|
|去全连接方式|最后一层 nin\_block 输出10通道 → GlobalAvgPool 直接分类|最后 Inception 输出1024通道 → GlobalAvgPool → 单层Linear分类|
|模块化程度|中等（全局统一单模块）|极高（Inception独立可插拔模块）|
|并行结构|无（纯串行堆叠）|有（四路径并行特征提取）|
|独特贡献|证明全连接层可被1×1卷积\+全局池化完全取代|证明多尺度自适应感受野优于人工固定核尺寸|
|计算效率|极高（轻量化无冗余参数）|中等（瓶颈优化后计算量可控）|

## 第五部分：各网络输入尺寸对比

针对深度学习常用数据集，整理主流CNN模型的原版输入尺寸与Fashion\-MNIST适配尺寸：

|网络|原版输入尺寸|Fashion\-MNIST 适配resize尺寸|
|---|---|---|
|LeNet|28×28|无需resize|
|AlexNet / VGG / NiN|224×224|224×224|
|GoogLeNet|224×224|96×96|

GoogLeNet选用96×96小尺寸的原因：Fashion\-MNIST为简单灰度小数据集，无需224大图；96×96经多次步长为2的池化后，可稳定得到3×3特征图，完美适配自适应池化1×1输出逻辑。

## 第六部分：网络结构排查技巧

训练时常出现 Linear(in\_features\) 维度不匹配报错，可通过以下代码快速逐层打印特征尺寸，精准定位维度问题：

```python
import torch

# 模拟单张输入图像
X = torch.rand(size=(1, 1, input_h, input_w))
# 逐层前向传播，输出每一层特征尺寸
for layer in net:
    X = layer(X)
    print(layer.__class__.__name__, '→', X.shape)
```

核心用途：快速获取Flatten层输入维度，精准匹配全连接层参数，解决维度不匹配报错。
