# 下一阶段数据采集与标定清单

日期：2026-09-11

这份清单用于解除Practical 04当前的 `BLOCKED`，不是可直接闭环控制的操作说明。

| 优先级 | 需要取得的证据 | 最低记录内容 | 能解除的阻断 | 仍不能单独证明什么 |
|---|---|---|---|---|
| P0 | 目标域负样本 | 空地、道路、杂草、残茬、田埂、围栏、人员/车辆；视频级来源ID | 目标域拒识测试缺失 | 不能单独证明正样本多行召回 |
| P0 | 逐帧走廊有效性真值 | `valid/invalid/ambiguous`、无效原因、标注者与复核者 | 真实视频false-valid/false-reject不可计算 | 不能替代几何边界标注 |
| P0 | 多行实例与走廊边界 | 每条可见行实例、左右相邻边界、中心、遮挡/截断属性 | 完整多行外部泛化未建立 | 不能自动得到米制距离 |
| P1 | 最高相关分组 | 农田、日期、相机、视频序列、作物品种、生长期 | 随机帧泄漏与同源高估风险 | 不能替代独立地域测试 |
| P1 | 相机内参和畸变 | 焦距、主点、畸变系数、分辨率、重投影误差 | 像素射线不可恢复 | 不能得到相机相对车体姿态 |
| P1 | 相机到车体外参 | 旋转、平移、坐标系定义、安装重复性 | 图像方向无法对应车体方向 | 不能替代地面模型 |
| P1 | 地面标定 | 平面/局部地形假设、单应性或深度、尺度物 | 图像偏移无法转为米制量 | 起伏地形仍需额外模型 |
| P2 | 时间与车辆信号 | 帧时间戳、速度、转角、里程计同步误差 | 无法做时间一致的影子模式分析 | 不能直接证明闭环安全 |

## 采集协议

1. 在采集前冻结标签规范、状态定义、纳入排除规则和数据角色；
2. 每段视频赋予不可变的field/date/camera/sequence标识；
3. 开发、OOD开发和冻结外部测试按最高相关单元拆分，禁止随机拆帧；
4. 冻结测试的媒体、标签和哈希在模型选择完成前不可访问；
5. 负样本不得只选“纯黑图”或明显无关图片，要覆盖会诱发作物行错检的真实结构；
6. 至少两人复核高风险valid帧和全部分歧帧，保留原始意见与裁决；
7. 记录数据许可和允许的再分发范围，未核验媒体只保留本地。

## 标定验收

- 相机内参：报告标定板覆盖范围和独立图像重投影误差；
- 相机外参：记录坐标轴、单位、安装高度/俯仰并进行重复装卸检查；
- 地面变换：在未参与拟合的地面控制点上报告米制误差；
- 时间同步：报告摄像头与车辆信号的偏差分布，而不是只写“已同步”；
- 所有标定文件都要带日期、设备序列号、分辨率和SHA-256。
