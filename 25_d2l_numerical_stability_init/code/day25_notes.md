# Day25：数值稳定性与模型初始化

**核心主题**：梯度消失 → 梯度爆炸 → 对称性破坏 → Xavier初始化

---

## 一、为什么初始化很重要？

之前我们一直在用 `torch.normal(0, 0.01, ...)` 或 `nn.init.normal_(std=0.01)` 来初始化参数。这看起来像是随手选的——但其实初始化方案的选择**直接决定了网络能不能训练**。

选错了，会出现两种灾难：

|灾难|现象|后果|
|---|---|---|
|**梯度消失**|梯度趋近于 0|参数几乎不更新，模型学不动|
|**梯度爆炸**|梯度巨大（$10^{26}$级别）|参数更新过猛，模型发散|

---

## 二、数学根源：链式求导中的连乘

考虑一个 L 层的深度网络，输出 **o** 对第 l 层参数 **W**\(l\) 的梯度是：

$\frac{\partial o}{\partial W^{(l)}} = M^{(L)} \cdot M^{(L-1)} \cdot ... \cdot M^{(l+1)} \cdot v^{(l)}$

其中每个 **M**\(k\) 是第 k 层对前一层的雅可比矩阵（偏导数矩阵），**v**\(l\) 是输出对 W\(l\) 的直接梯度。

这意味着梯度是 **L − l 个矩阵连乘**的结果。

🧠 **关键直觉**：如果有 100 个矩阵，每个矩阵的特征值要么都大于 1，要么都小于 1——

- 都 \> 1：连乘结果爆炸 →**梯度爆炸**

- 都 \< 1：连乘结果趋近于 0 → **梯度消失**

## 三、梯度消失（Vanishing Gradient）

### 3\.1 罪魁祸首：Sigmoid 函数

Sigmoid 曾经是神经网络最流行的激活函数（它长得很像生物神经元的"激活/不激活"行为）：

$\text{sigmoid}(x) = \frac{1}{1 + e^{-x}}$

### 3\.2 可视化实验（代码核心）

```python
x = torch.arange(-8.0, 8.0, 0.1, requires_grad=True)
y = torch.sigmoid(x)
y.backward(torch.ones_like(x))  # 求 sigmoid 的导数
# 绘图：蓝色实线=sigmoid，紫色虚线=它的梯度
d2l.plot(x.detach().numpy(), [y.detach().numpy(), x.grad.numpy()],
         legend=['sigmoid', 'gradient'], figsize=(4.5, 2.5))
```

### 3\.3 图像解读

从图中可以看到：

sigmoid 曲线：       从 0 缓慢上升到 1，像一个拉长的 "S"

sigmoid 的梯度曲线：  中间凸起（x≈0 时梯度最大 ≈0\.25），两端迅速趋近于 0

当 x = \-8 时：sigmoid ≈ 0，梯度 ≈ 0\.0003  ← 几乎为 0

当 x =  0 时：sigmoid = 0\.5，梯度 = 0\.25  ← 最大也只有 0\.25

当 x =  8 时：sigmoid ≈ 1，梯度 ≈ 0\.0003  ← 几乎为 0

🔑 Sigmoid 的梯度最大只有 0\.25。假设网络有 10 层，每层都用 Sigmoid，则梯度最多连乘 10 次：$0.25^{10} \approx 0.000001$。传到最前面的层，梯度已经消失殆尽。

### 3\.4 为什么 ReLU 能缓解？

对比（Day22 学过）：

|激活函数|输入 \> 0 时的梯度|梯度消失风险|
|---|---|---|
|Sigmoid|最大 0\.25，两端趋近 0|❌ 严重|
|ReLU|恒为 1（不衰减！）|✅ 大幅缓解|

这就是为什么 ReLU 几乎取代了 Sigmoid 成为隐藏层的默认选择。

## 四、梯度爆炸（Gradient Explosion）

### 4\.1 实验：100 个随机矩阵连乘

```python
M = torch.normal(0, 1, size=(4, 4))  # 一个普通的 4×4 随机矩阵
for i in range(100):
    M = torch.mm(M, torch.normal(0, 1, size=(4, 4)))
print('乘以100个矩阵后\n', M)
```

### 4\.2 实验结果

一个矩阵（初始）：

tensor\([[-0\.7872,  2\.7090,  0\.5996, -1\.3191\],

         [-1\.8260, -0\.7130, -0\.5521,  0\.1051\],

         [ 1\.1213,  1\.0472, -0\.3991, -0\.3802\],

         [ 0\.5552,  0\.4517, -0\.3218,  0\.5214\]\]\)

乘以100个矩阵后：

tensor\([[-2\.1897e\+26,  8\.8308e\+26,  1\.9813e\+26,  1\.7019e\+26\],

         [ 1\.3110e\+26, -5\.2870e\+26, -1\.1862e\+26, -1\.0189e\+26\],

         [-1\.6008e\+26,  6\.4559e\+26,  1\.4485e\+26,  1\.2442e\+26\],

         [ 3\.0943e\+25, -1\.2479e\+26, -2\.7998e\+25, -2\.4050e\+25\]\]\)

|维度|初始值范围|100 次连乘后|
|---|---|---|
|数值|\-1\.8 \~ 2\.7|$10^{26}$ 级别|
|尺度变化|个位数|二十六次方|

💥 仅仅 100 次矩阵乘法，数值从个位数膨胀到了 $10^{26}$（1 后面 26 个零）——这是天文学级别的爆炸。

### 4\.3 为什么会爆炸？

每个随机矩阵的元素来自 $N(0, 1)$，其谱半径（最大特征值的绝对值）大概率 \> 1。连乘 100 次后，特征值按指数增长，梯度同理。

## 五、梯度消失 vs 梯度爆炸：直观对比

梯度消失                          梯度爆炸

────────                          ────────

梯度的值：       grad ≈ 0                        grad ≈$10^{26}$

参数更新幅度：    几乎为零（原地不动）               大到飞出去（发散）

训练表现：       loss 一直不下降                    loss 变成 NaN

类比：           发动机没油了                       油门踩到底炸了

🎯 这两种情况都导致网络无法训练。好的初始化就是让梯度保持在"刚刚好"的范围。

## 六、打破对称性

### 6\.1 问题：全常数初始化

如果把隐藏层所有神经元的参数初始化成相同的值（比如全 0 或全 c），会发生什么？

前向传播：所有隐藏单元输出相同

反向传播：所有隐藏单元的梯度也相同

参数更新：权重矩阵的每一行都做同样的更新 → 永远保持相同！

结果：隐藏层的 n 个神经元等价于 1 个神经元——网络的表达能力荡然无存。

### 6\.2 解决方案

随机初始化——用不同的随机值初始化每个参数，从一开始就打破对称性。这也是为什么我们一直用 `torch.normal(0, 0.01, ...)` 或`torch.randn(...)` 而不是 `torch.zeros(...)`。

📌 补充：即使不用随机初始化，Dropout（Day24）也能在训练过程中打破对称性，但随机初始化是最简单直接的办法。

## 七、Xavier 初始化（Glorot 初始化）

### 7\.1 目标

让每一层的输出方差和梯度方差在传播过程中保持稳定——不会逐层放大或缩小。

### 7\.2 推导思路（简化版）

考虑一个没有激活函数的全连接层，有 $n_{in}$ 个输入：

$o = w_1 \cdot x_1 + w_2 \cdot x_2 + ... + w_{n_{in}} \cdot x_{n_{in}}$

假设：

- 权重 w 的均值为 0，方差为 $\sigma^2$

- 输入 x 的均值为 0，方差为 $\gamma^2$

- w 和 x 互相独立

则输出 o 的方差为：

$\text{Var}(o) = n_{in} \cdot \sigma^2 \cdot \gamma^2$

为了在前向传播中保持方差不变（$\text{Var}(o) = \text{Var}(x) = \gamma^2$），需要：

$n_{in} \cdot \sigma^2 = 1 \quad \Rightarrow \quad \sigma^2 = \frac{1}{n_{in}} \quad （前向约束）$

同理，反向传播时考虑输出端有 $n_{out}$ 个神经元，需要：

$n_{out} \cdot \sigma^2 = 1 \quad \Rightarrow \quad \sigma^2 = \frac{1}{n_{out}} \quad （反向约束）$

但两个条件不可能同时满足。Xavier 的折中方案：

$\sigma^2 = \frac{2}{n_{in} + n_{out}} \quad （取两者的调和平均）$

### 7\.3 Xavier 初始化的两种形式

|分布|参数|公式|
|---|---|---|
|高斯分布|均值 = 0，方差 $\sigma^2$|$\sigma = \sqrt{\frac{2}{n_{in} + n_{out}}}$|
|均匀分布 U\(\-a, a\)|区间边界 a|$a = \sqrt{\frac{6}{n_{in} + n_{out}}}$|

### 7\.4 PyTorch 中的 Xavier

```python
# Xavier 高斯
nn.init.xavier_normal_(m.weight)
# Xavier 均匀（默认更常用）
nn.init.xavier_uniform_(m.weight)
```

### 7\.5 为什么 Xavier 有效？

直觉：$n_{in}$ 越大 → 求和项越多 → 输出方差越大。Xavier 通过让方差与 $n_{in}$ 成反比来抵消这个效应。每层输出的尺度稳定 → 梯度也稳定 → 深层网络也能训练。

### 7\.6 Xavier 的局限

Xavier 假设激活函数是线性的（或近似线性），对 ReLU 效果打折扣。后来出现了针对 ReLU 的 Kaiming/He 初始化（后续会遇到）：

$\text{Kaiming}: \sigma^2 = \frac{2}{n_{in}} \quad （只考虑前向，适配 ReLU 的"一半神经元激活一半死"的特性）$

## 八、初始化方法速查

|初始化方法|$\sigma^2$（方差）|适用激活函数|PyTorch|
|---|---|---|---|
|默认|$N(0, 0.01^2)$|浅层网络|手动指定|
|Xavier 高斯|$2/(n_{in}+n_{out})$|Sigmoid / Tanh|xavier\_normal\_|
|Xavier 均匀|$U(-a, a), a^2=6/(n_{in}+n_{out})$|Sigmoid / Tanh|xavier\_uniform\_|
|Kaiming 高斯|$2/n_{in}$|ReLU / LeakyReLU|kaiming\_normal\_|
|Kaiming 均匀|$U(-a, a), a^2=6/n_{in}$|ReLU / LeakyReLU|kaiming\_uniform\_|

📌 从现在开始，搭网络时养成指定初始化的好习惯，不要依赖框架默认值。

|---|---|---|
|①|梯度消失根源|L 层网络梯度是 L−l 个矩阵连乘，特征值 \< 1 时指数衰减|

|⑥|Xavier 核心公式|$\sigma^2 = 2/(n_{in}+n_{out})$，折中前向和反向的方差约束|
|⑦|Xavier 用于哪里|Sigmoid/Tanh 激活，对于 ReLU 应改用 Kaiming 初始化|
