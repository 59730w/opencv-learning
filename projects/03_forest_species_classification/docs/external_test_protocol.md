# 外部图片测试协议

制定日期：2026-08-14

## 目的

测试ResNet18模型面对独立来源、不同设备、不同地区和不同拍摄条件时的泛化能力。

外部测试结果不用于重新训练、调整参数或重新选择检查点。

## 正样本

固定测试以下10个BarkVN-50类别：

1. Anacardium occidentale
2. Artocarpus heterophyllus
3. Carica papaya
4. Cocos nucifera
5. Delonix regia
6. Hevea brasiliensis
7. Psidium guajava
8. Tamarindus indica
9. Tectona grandis
10. Terminalia catappa

每个类别准备2张图片，共20张。

每个类别尽量包含：

- 1张树皮或茎干近景；
- 1张稍宽的树干图；
- 两张图片来自不同观察记录、网页或摄影者；
- 图片来源不能是BarkVN-50或其镜像；
- 物种标签必须由来源页面明确给出；
- 必须记录原始页面、作者和许可证。

正样本文件命名格式：`positive_类别索引_序号.jpg`。

例如：`positive_03_01.jpg`。

## 负样本

准备6张不属于当前输入范围的图片：

1. 森林远景
2. 叶片近景
3. 花朵
4. 果实
5. 岩石纹理
6. 建筑或木板纹理

负样本没有正确的50类标签。模型是闭集分类器，必然输出某个类别，因此负样本只用于观察错误类别和置信度，不能计算准确率。

负样本文件命名格式：`negative_类别_序号.jpg`。

## 固定评价方法

正样本报告：

- Top-1正确数量
- Top-1准确率
- Top-3正确数量
- Top-3准确率
- 每张图片的Top-3类别及概率
- 近景和稍宽树干图的表现差异

负样本报告：

- Top-1预测类别
- Top-1置信度
- 是否出现高置信度强制分类

## 防止测试集污染

- 下载前固定测试类别和数量；
- 不根据预测结果更换失败图片；
- 不用外部图片继续训练当前基线；
- 保留失败结果；
- 若未来改进模型，必须建立新的外部验证集，不能反复针对本批图片调参。
