# ResNet18 基线训练记录

训练日期：2026-08-13

## 任务

使用BarkVN-50树皮/茎干近景图像进行50类别植物物种分类。

本项目属于图像处理与机器视觉学习任务，不宣称能够识别任意森林树种、整棵树或森林远景。

## 数据划分

- 训练集：3,891张
- 验证集：844张
- 测试集：823张
- 类别数：50
- 划分单位：感知哈希相似组
- 跨子集相似组：0
- 测试集尚未用于训练或模型选择

## 模型与环境

- 模型：ImageNet预训练ResNet18
- 输出类别：50
- 输入尺寸：224×224
- GPU：NVIDIA GeForce RTX 3050 Laptop GPU
- PyTorch：2.5.1+cu121
- AMP：启用
- 批次大小：16
- 优化器：AdamW
- 损失函数：CrossEntropyLoss
- 随机种子：42

## 训练方案

第一阶段只训练分类头：

- 轮数：3
- 学习率：0.001
- 可训练参数：25,650

第二阶段微调整个模型：

- 轮数：12
- 学习率：0.0001
- 可训练参数：11,202,162

总训练轮数：15。

## 最佳验证结果

按照验证集Macro-F1选择最佳检查点：

- 最佳轮次：第13轮
- 阶段：全模型微调
- 验证损失：0.0738
- 验证准确率：97.87%
- 验证Macro-F1：0.9761
- 最佳权重：`checkpoints/resnet18_baseline/best.pt`

后续正式评估必须使用`best.pt`，不能使用第15轮的`last.pt`。

## 训练曲线分析

1. 前3轮只训练分类头，验证Macro-F1从0.6364提升到0.7877。
2. 第4轮解冻骨干网络后，验证Macro-F1快速提升到0.9337，说明迁移学习有效。
3. 第7至14轮整体处于较高水平，验证Macro-F1约为0.94～0.98。
4. 第13轮取得最佳结果。
5. 第15轮训练准确率仍为98.48%，但验证损失升至0.1509，验证Macro-F1降至0.9551，表现出轻微过拟合或训练波动。
6. 最佳检查点机制成功避免使用性能回落的最后一轮权重。

## 当前结论

ResNet18已经建立了较强的验证集基线，但验证集高分不等于真实场景泛化能力已经得到证明。

后续仍需：

- 仅使用一次独立测试集进行正式评估；
- 报告Accuracy和Macro-F1；
- 生成50类分类报告与混淆矩阵；
- 检查代表性错误预测；
- 使用独立来源的外部图片测试泛化能力；
- 明确数据集缺少树木个体、地点和拍摄批次元数据这一限制。
