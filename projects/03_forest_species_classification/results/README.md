# Selected results

This folder contains small, tracked evidence needed to audit the reported conclusions. Full run directories remain ignored.

- `data_audit/`: quality, duplicate and similarity-group summaries.
- `resnet18_baseline/`: training history, official test metrics and per-class results.
- `external_test/`: strict external predictions, metrics, leakage-risk evidence and final report.
- `external_test_posthoc_multicrop/`: explicitly post-hoc five-crop exploration.

The strict external baseline must not be replaced by the post-hoc experiment.
