## 一、从全连接到卷积

### 1\.1 全连接层的问题

回顾 Day22 的 MLP：输入一张 28×28 的 Fashion\-MNIST 图片，第一层是 nn\.Linear(784, 256\)。

参数量计算：784 \* 256 \+ 256 = **200960 个**参数。

这还只是灰度小图。如果是一张 1000×1000 的彩色森林照片：

输入维度：1000 \* 1000 \* 3 = 3000000

    隐藏层1000个神经元参数量：3000000 \* 1000 = **30亿**个参数

❌ **两大致命问题**：参数量爆炸、所有像素一视同仁，丢失图像空间结构信息

### 1\.2 卷积的两个核心改进

|改进|说明|效果|
|---|---|---|
|**局部连接**|每个神经元只看输入的一小块区域（如 3×3），不是全部像素|参数量从亿级降到千级|
|**参数共享**|同一个卷积核在整张图上滑动，所有位置共享同一组权重|无论图片多大，参数量固定不变|

🧠 直觉：全连接是「每个输出点参考输入的全部点」；卷积是「每个输出点只参考输入的一个小窗口，而且所有窗口用同一套参数」。

## 二、二维互相关运算

### 2\.1 互相关运算 vs 卷积运算

严格数学意义上的**卷积**需要把卷积核**上下左右翻转**后再做滑动运算。

深度学习中的「卷积」实际上是**互相关（cross\-correlation）**——不做翻转，直接滑动求内积。

数学卷积：先翻转卷积核，再滑动计算

    深度学习卷积：不翻转卷积核，直接滑动计算（互相关）

核心原因：卷积核参数是模型学习得到的，翻转与否不影响最终效果，因此深度学习直接使用互相关，省去翻转操作，提升效率。

### 2\.2 手写实现 corr2d

```python
def corr2d(X, K):
    """计算二维互相关运算
    X: 输入矩阵 (H, W)
    K: 卷积核   (h, w)
    返回: 输出矩阵 (H-h+1, W-w+1)
    """
    h, w = K.shape
    Y = torch.zeros((X.shape[0] - h + 1, X.shape[1] - w + 1))
    # 遍历输出矩阵每一个位置
    for i in range(Y.shape[0]):
        for j in range(Y.shape[1]):
            # 局部窗口逐元素相乘后求和
            Y[i, j] = (X[i:i+h, j:j+w] * K).sum()
    return Y
```

### 2\.3 计算实例

输入 X (3×3\)：

[0, 1, 2\]

[3, 4, 5\]

[6, 7, 8\]

卷积核 K (2×2\)：

[0, 1\]

[2, 3\]

逐位置计算结果：

Y[0,0\] = 0\*0 \+ 1\*1 \+ 3\*2 \+ 4\*3 = 0 \+ 1 \+ 6 \+ 12 = 19

Y[0,1\] = 1\*0 \+ 2\*1 \+ 4\*2 \+ 5\*3 = 0 \+ 2 \+ 8 \+ 15 = 25

Y[1,0\] = 3\*0 \+ 4\*1 \+ 6\*2 \+ 7\*3 = 0 \+ 4 \+ 12 \+ 21 = 37

Y[1,1\] = 4\*0 \+ 5\*1 \+ 7\*2 \+ 8\*3 = 0 \+ 5 \+ 14 \+ 24 = 43

最终输出 Y (2×2\)：

[19, 25\]

[37, 43\]

### 2\.4 输出尺寸公式

输出高度 = 输入高度 \- 卷积核高度 \+ 1

    输出宽度 = 输入宽度 \- 卷积核宽度 \+ 1

通用公式：

    H\_out = H \- h \+ 1

    W\_out = W \- w \+ 1

示例验证：3×3输入 \+ 2×2卷积核，输出尺寸 = 3\-2\+1 = 2，最终得到 2×2 输出。

## 三、手写卷积层 Conv2D

### 3\.1 完整实现代码

```python
import torch
import torch.nn as nn

class Conv2D(nn.Module):
    def __init__(self, kernel_size):
        super().__init__()
        # 可训练卷积核权重
        self.weight = nn.Parameter(torch.rand(kernel_size))
        # 可训练偏置
        self.bias   = nn.Parameter(torch.zeros(1))

    def forward(self, x):
        # 互相关运算 + 偏置广播
        return corr2d(x, self.weight) + self.bias
```

|组件|形状|说明|
|---|---|---|
|self\.weight|\(h, w\)|卷积核，尺寸由 kernel\_size 决定|
|self\.bias|\(1,\)|标量偏置，自动广播到输出每个位置|
|输出|(H\-h\+1, W\-w\+1\)|互相关计算结果叠加偏置|

结合Day27知识点：卷积核权重通过 nn\.Parameter 注册，PyTorch 自动追踪梯度、参与反向传播更新。

## 四、卷积的应用：边缘检测

### 4\.1 构造测试图像

```python
# 生成 6行8列 全1矩阵
X = torch.ones((6, 8))
# 中间4列置0，制造两条垂直边缘
X[:, 2:6] = 0
```

图像结构说明：

所有行结构一致：\[1, 1, 0, 0, 0, 0, 1, 1\]

生成两条垂直边缘：

    1-2列：亮\(1\) → 暗\(0\)

    5-6列：暗\(0\) → 亮\(1\)

### 4\.2 垂直边缘检测卷积核

```python
# 1×2 水平卷积核
K = torch.tensor([[1.0, -1.0]])
```

运算逻辑：

    单点计算结果 = x\_left \* 1 \+ x\_right \* \(\-1\) = x\_left \- x\_right

- 左右像素相同：差值 = 0（无边缘，平坦区域）

- 左1、右0：差值 = 1（亮转暗垂直边缘）

- 左0、右1：差值 = \-1（暗转亮垂直边缘）

### 4\.3 检测结果

```python
Y = corr2d(X, K)
```

输出矩阵 Y 尺寸为 6×7，所有行结果一致：[0, 1, 0, 0, 0, \-1, 0\]

- 第1列为1：检测到亮→暗垂直边缘

- 第5列为\-1：检测到暗→亮垂直边缘

- 其余位置为0：像素无变化，无边缘

🎯 结论：1×2卷积核 [1, \-1\] 是经典的**垂直边缘检测器**。

### 4\.4 卷积核方向性验证

```python
# 图像转置，垂直边缘变为水平边缘
corr2d(X.t(), K)
```

运行结果：输出几乎全部为0，无法检测水平边缘。

📌 核心规律：卷积核具备固定方向性，**水平排列卷积核检测垂直边缘，竖直排列卷积核检测水平边缘**。

## 五、自动学习卷积核（核心实验）

前面手动设计卷积核实现边缘检测，本实验实现：**无需人工设计，让模型从数据中自动学习最优卷积核**。

### 5\.1 数据维度适配（CNN标准4维格式）

```python
# 维度变换：(H, W) -> (batch, channel, H, W)
X = X.reshape((1, 1, 6, 8))
Y = Y.reshape((1, 1, 6, 7))
```

### 5\.2 模型与超参数配置

```python
# 输入通道1、输出通道1、卷积核1×2、关闭偏置
conv2d = nn.Conv2d(1, 1, kernel_size=(1, 2), bias=False)
lr = 3e-2  # 学习率 0.03
```

### 5\.3 完整训练循环

```python
for i in range(10):
    Y_hat = conv2d(X)                # 前向传播
    l = (Y_hat - Y) ** 2             # MSE损失计算
    conv2d.zero_grad()               # 梯度清零
    l.sum().backward()               # 反向传播求梯度
    # 手动SGD更新卷积核参数
    conv2d.weight.data[:] -= lr * conv2d.weight.grad
    # 每2轮打印损失
    if (i + 1) % 2 == 0:
        print(f'epoch {i+1}, loss {l.sum():.3f}')

# 输出模型学习到的卷积核
print(conv2d.weight.data.reshape((1, 2)))
```

### 5\.4 实验结果与核心发现

训练损失迭代趋势：

- epoch2：损失小幅下降

- epoch4：损失持续降低

- epoch6：损失接近0\.01级

- epoch8：损失接近0\.001级

- epoch10：损失趋近于0，完全收敛

最终学习到的卷积核无限接近：[1\.0000, \-1\.0000\]，与人工设计的最优核完全一致。

🎯 核心结论：**卷积核不需要人工设计，可通过数据驱动自动学习**，这是卷积神经网络CNN的核心能力。

## 六、nn\.Conv2d 参数详解

```python
nn.Conv2d(in_channels, out_channels, kernel_size, bias=True)
```

|参数|本实验取值|含义|
|---|---|---|
|in\_channels|1|输入通道数，灰度图=1，RGB彩色图=3|
|out\_channels|1|输出通道数，等价于卷积核个数|
|kernel\_size|\(1, 2\)|卷积核尺寸 \(高度, 宽度\)|
|bias|False|关闭偏置，匹配纯卷积运算逻辑|

### 张量形状规则（CNN标准四维张量）

输入格式：(batch\_size, in\_channels, H, W\)

    输出格式：(batch\_size, out\_channels, H\_out, W\_out\)

尺寸变换规则：

    H\_out = H \- kernel\_h \+ 1

    W\_out = W \- kernel\_w \+ 1

本实验维度变化：\(1, 1, 6, 8\) → 卷积运算 → \(1, 1, 6, 7\)

## 七、全连接 vs 卷积：参数量的天壤之别

|网络层|输入|输出|参数量|
|---|---|---|---|
|全连接 nn\.Linear|28×28=784|256 神经元|200960|
|卷积 nn\.Conv2d|1×28×28|256 通道|2560|

卷积参数量比全连接**减少近80倍**，同时保留图像空间结构、具备平移不变性，模型泛化能力更强、精度更高。
